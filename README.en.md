# Dafeiyu Studio 🐟

<p align="center">
  <b>AI agent workstation on your phone</b><br>
  Run an AI agent locally on Android, no ROOT required
</p>

A no-ROOT Android app that packs a complete AI agent framework into your phone. It runs a local Linux environment where the AI can actually execute commands, read/write files, and operate the device — not just chat.

Deep-sea blue theme with a "big fat fish" mascot. A fully personal project.

## Highlights

- **No ROOT, no Termux**: runs Linux on the phone via proot
- **Local execution**: built-in Ubuntu environment (~300MB) with Node.js + AI agent pre-installed
- **AI that acts**: execute commands, manage files, control the device
- **Plugin system**: built-in plugins, ready on first launch

## Build

Requires JDK 17, Android SDK 34, NDK 26, Gradle 8.5.
